# 『ひたすら広告』仕様書⑥

## ― 全151広告・正式名称・図鑑表示仕様 ―

## 1. 基本方針

探索広告 `AD_001` ～ `AD_151` には、それぞれ**固定された正式名称**を設定する。

広告生成時に文章・数字・画像・演出が変化しても、図鑑上の名称と広告IDは変化しない。

図鑑表示例：

```text
No.037

王様、また燃える

RARE

「正解を選んだはずなのに。」
```

未発見時：

```text
No.037

？？？？？？？？？

未発見
```

---

# 2. 名称設計原則

広告名は、

* 広告あるある
* 誇大広告
* 怪しい通販
* スマホゲーム広告
* レトロWeb
* AI広告
* 診断広告
* ガチャ
* オリパ
* ギャンブル風演出
* 無意味な煽り

などへのパロディ・皮肉を中心とする。

実在するサービス、商品、企業、ゲーム、キャラクター等の固有名称は直接使用しない。

# 5. No.151の名称について

No.151は「どこか懐かしい収集ゲームの幻キャラクターっぽさ」を狙う。

ただし実在キャラクターの名前・デザイン・鳴き声・能力・UI等はコピーしない。

名称候補：

* アドゴン
* コクコク
* アドミュウム
* センデンヌ
* コウコック
* アドノイド
* PR-X151

初期正式名称は、

# 「幻の広告 ― アドゴン」

とする。

開発中により良い完全オリジナル名称が出た場合のみ変更可能。

# 8. 図鑑データ構造

各広告は最低限以下を保持する。

```text
id
number
name
description
category
rarity
interactionType
targetTags
unlockCondition
isDiscovered
firstDiscoveredAt
```

例：

```text
id: AD_037
number: 37
name: 王様、また燃える
description: 正解を選んだはずなのに。
category: pin_pull
rarity: RARE
```

---

# 12. 名前の固定

Codexが自動生成するランダムキャッチコピーと、

**図鑑正式名称**

を混同しないこと。

例えばAD_005の表示広告内では、

```text
緊急SALE！
今だけ1円引き！
```

等に毎回変化してよい。

しかし図鑑名は常に、

# 「驚異の1円OFF！」

とする。

---

# 13. 151種類を正式データ化

今回定義した151名称を、単なる仕様書文章のままにせず、

```text
ad_catalog.json
```

またはDartの定義データとして正式に登録する。

広告番号・名称・説明文の重複や欠番がないことを自動テストする。

---

# 14. 必須テスト

以下を自動検証する。

* 001～151がすべて存在
* ID重複なし
* number重複なし
* 正式名称空欄なし
* 説明文空欄なし
* 151だけSECRET
* 151だけ通常抽選対象外
* 001～150コンプリート前に151が出ない
* 150種類発見後151が解禁
* 図鑑が151件表示可能
* 発見済み件数が正しく計算される

---

# 15. 最終方針

広告図鑑は単なる、

```text
37 / 151
```

という数字だけの画面にしない。

ユーザーが、

> 「次はどんなバカ広告なんだ？」

と続きを見たくなるよう、

**151種類すべてに名前と人格を与える。**

広告を見る。

変な広告が出る。

名前で笑う。

図鑑に登録される。

残りが気になる。

また広告を見る。

そして最後に、

# No.151

# 幻の広告 ― アドゴン

へ到達する。

これを『ひたすら広告』初期版の収集ゲーム部分の完成形とする。

# 151種類。以上。
