## Game Stage

`AdGameStage`が広告を開いた時点で必要な背景1枚だけを読み込み、次の順序で描画する。

1. 背景画像
2. 可読性オーバーレイ
3. コード描画のゲーム盤・判定領域
4. 前景画像・敵・目標物
5. 成功・失敗UI

画像と衝突判定は分離している。透明部分に依存せず、44px以上のWidget領域でタップ・ドラッグを判定する。画像ロード失敗時は広告番号とパスをdebugログへ出し、コード描画へフォールバックする。

## ゲーム性

|タイプ|画像統合後の実装|
|---|---|
|タップ|前景画像そのものをHitAreaにし、タップごとに移動・拡縮|
|選択|前景・副素材を選択ボタン内へ配置|
|ドラッグ|前景画像自体を`Draggable`として移動。正解枠へsnap、誤答は元位置へ復帰|
|線描画|主人公と敵/目標をステージ両端へ置き、その間へ線を描画|
|ピン抜き|王様、宝箱/危険物、コード描画ピンを同一ステージへ配置|
|タイミング|コード描画ゲージと反応キャラクターを同一ステージへ配置|
|スクラッチ|画像世界の上でスクラッチ面を操作|
|パック開封|画像付きパック自体を上へスワイプ|
|カウントダウン|コード描画タイマーと反応キャラクターを統合|
|再発見|移動する前景画像自体をタップ|
|フィナーレ|No.151専用進捗と画像・背景を統合。解放規則は未変更|

成功時は対象画像を拡大し、失敗時は傾き・縮小・減光する。リトライでは進捗、線、ピン、スクラッチ、ドラッグ距離、タイマー、画像状態を初期化する。
