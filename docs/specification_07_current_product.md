# 『ひたすら広告』仕様書⑦

## ― 基本思想再定義・メインUI全面再構築・151広告個別実装 ―

## 1. この仕様書の目的

現在の『ひたすら広告』は基本機能自体は動作し始めているが、UIおよび広告表示体験が、当初のアプリコンセプトから外れている。

現在確認できる主な問題は以下。

* HOMEがダッシュボード化している
* 「WATCH NOW」を押しても広告体験が始まらない
* 英語表記が多い
* 視聴時間・総視聴時間・視聴数・発見数等がHOMEを占有している
* HOMEにランキング・探索・図鑑等の導線が重複している
* スクロールが必要
* 「広告を見る」という主目的が画面中央に存在しない
* 広告が単なるカード表示になっている
* 151広告の個性・演出が実際の体験として表現されていない
* 「広告を見せられる」という本アプリ固有の体験が弱い

したがって今回、

# HOMEを一度根本から再設計する。

この仕様書以降、本アプリのUI・UXは本仕様書を優先すること。

---

# 2. 基本思想を再確認する

このアプリは、

# 広告管理アプリではない。

# 広告統計アプリでもない。

# ダッシュボードでもない。

ユーザーがアプリを開いたら、

# 広告を見る。

これが中心である。

基本ループは以下だけ。

```text
アプリを開く
↓
中央の巨大な「広告を再生する」
↓
151種類からランダムで1広告抽選
↓
画面中央に広告がドーンと表示
↓
一定時間広告を見る
↓
広告終了
↓
新規なら図鑑登録
↓
また「広告を再生する」
```

このループを最優先する。

# 3. HOMEの役割を一つに絞る

HOMEは、

# 広告を再生するためだけの画面

とする。

HOMEから以下を削除する。

* 本日の視聴時間カード
* 累計視聴時間カード
* 視聴数カード
* 発見数カード
* 同じ機能へ複数存在する導線

* 巨大な統計ダッシュボード
* 不要なスクロール領域

これらは「記録」画面へ移動する。

ただし、


# 21. ただし広告の複雑さには差をつける

151種類すべてをミニゲーム化する必要はない。

広告を以下に分ける。

### A. シンプル広告

静止画＋文字＋軽い点滅。

### B. アニメーション広告

文字・画像が動く。

### C. 操作広告

タップ・ドラッグ等。

### D. ミニゲーム広告

王様、スロット等。

### E. 特殊広告

レア／SECRET。

これを混在させる。

# 50. 最終原則

このアプリでユーザーが考えることは、

# 「次、何の広告が出るんだろう」

だけでよい。

統計を眺めることを中心にしない。

複雑なメニューを操作させない。

画面をスクロールさせない。

英語だらけにしない。

広告をカードとして説明しない。
